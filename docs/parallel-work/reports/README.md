# Task reports

## Accepted local milestones

- [October 18 coordinated wave](coordinator-wave1.md): dependency/exclusion editing and reviewed intelligence, rubric, installation, accessibility and operations increments.
- [October 20 segmented implementation](coordinator-segmented.md): durable synthetic runs, human handoff and schema-10 recovery.
- [October 20 adoption wave](coordinator-adoption.md): fresh-install rehearsal, accessible validation and read-only operator diagnostics; latest assembled validation evidence.

Acceptance is limited to each report's scope. Proposals, outside-person adoption, human rubric
adjudication and production readiness are not completed by technical review. Consult the
[current project status](../../open-source-plan.md#current-implementation-and-remaining-work)
and [independent trial checklist](../../independent-trial.md) for next work.

For a newly assigned increment, use [the report template](../report-template.md) and the exact
filename assigned in the workboard. Record non-author review and integration evidence before
marking it accepted. Historical agent names and reservations do not assign a new session.

Keep credentials, private source material, raw local logs, backups and offline packets outside this
directory. Use synthetic examples and concise evidence summaries in releasable reports.
