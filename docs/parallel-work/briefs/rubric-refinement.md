# RUB-01 — Remaining rubric precision candidates

Follow-up assignment; start when the coordinator grants a slot and confirms the frozen rubric
baseline. Read AGENTS.md, `docs/rubric-precision.md`, `docs/rubric-adoption.md`, the original
definition mapping and existing laboratory cases. Do not alter existing labels or measure weights.

Owned output: `docs/rubric-next.md`, `scripts/rubric-lab/next-candidate.ts`,
`scripts/rubric-lab/next-cases.ts`, `test/unit/rubric-next.test.ts`, and `reports/RUB-01.md`.
The frozen current candidate, defaults, Settings and application scoring remain coordinator-owned.

Review the remaining 36 measures in small, explicitly identified batches. For each, propose source
scope, subrequirements, polarity, decisive exceptions, supported/partial/opposed/silent/unresolved
boundaries, and minimal paired synthetic examples. Separate an explicit violation from absent
wording; silence requires applicable complete source coverage. Keep all labels provisional.

Preserve original IDs, weights and historical outputs. New candidates use new identities and have
no application adoption authority. Do not evaluate legal compliance or declare district policy
accepted. Request independent challenge of the case design; holdout labels must not be exposed to
the system being evaluated. Agent review does not substitute for qualified human adjudication.

Acceptance: batch inventory, executable synthetic boundary cases, documented ambiguous choices,
non-author critique and a human-adjudication packet. The coordinator chooses subsequent batches and
any explicitly versioned pilot integration; do not automatically replace the existing rubric.
